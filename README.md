# Дома есть

Публичная сборка приложения: https://egor777-7.github.io/family-menu/

Репозиторий содержит только готовые HTML, CSS, JavaScript, шрифты и изображения для GitHub Pages. Исходные TypeScript-файлы, история рабочего проекта, ключи и пользовательские данные сюда не публикуются.

`data/openfoodfacts-ru.json` — выборка товаров «продаётся в России» из открытой базы [Open Food Facts](https://world.openfoodfacts.org/), лицензия [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/). Фото упаковок `images/products/alt-off-*.jpg` сделаны участниками Open Food Facts и распространяются по [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
